# Hotel Booking Cancellation Prediction 🏨

This project was created for the "Data Mining and Visualization" course at university. The goal is to predict whether a hotel booking will be canceled based on data.

## 📊 Summary

- Records: 27,213 hotel bookings
- Goal: Predict cancellation (`is_canceled`)
- Models used: Decision Tree, Random Forest, CatBoost

## 🧠 Techniques

- Data cleaning and preprocessing
- Feature engineering (e.g., stay length)
- Normalization and missing value handling
- Classifier comparison using F1-score, AUC, etc.
- Final model: Random Forest

## 📁 Files

- `final_project_notebook.ipynb`: Main notebook with all code
- `Final_Project_Document.pdf`: Project report
